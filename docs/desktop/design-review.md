# Native companion design review

The baseline was the clean functional gate at `a3de2d1`. The review used the pinned local Emil Kowalski references for immediate navigation, purposeful feedback, reduced motion and testing at the limits of real data. The native GTK packages ran in isolated X11/Openbox sessions on Ubuntu 24.04.5 LTS with separate D-Bus sessions, disposable runner and coordinator roots, and loopback UDP.

## Native verification

- The GTK fixture admitted the disposable cards, started the owned runner, observed authenticated reachability, stopped the runner and acquired the released instance lock independently. A subsequent failed probe kept the earlier Last reached timestamp. Restart and closing the companion with an owned child both passed.
- The real offline export displayed Unreachable at last check with separate Checked and Last reached timestamps. Demo run #1042 displayed Unknown, no verified start, no verified result and a delivered message. Run #1041 displayed verified start and result with message delivery pending. The UI review exercised these display states using fixture snapshots.
- GTK recorded 12 consecutive Nodes/Jobs switches in each rapid pass. Every switch appeared in the first post-action accessibility snapshot. The observations include driver overhead. The reduced-motion run used fixture-local `gtk-enable-animations=false`. App feedback uses immediate color and text changes. The short trajectory records the wheel scroll and both subsequent page switches. [Default trace](../../.desktop-attempt/design-review/final/navigation-trace/) · [Reduced-motion trace](../../.desktop-attempt/design-review/wheel-after/navigation-trace/)
- The AT-SPI element-targeted wheel path hit a GLib assertion on both builds in the full fixture. Window-coordinate wheel input reproduced the scroll defect and verified the fix on the same fixture. [Baseline diagnostic](../../.desktop-attempt/design-review/scroll-before/gtk.log) · [Revised diagnostic](../../.desktop-attempt/design-review/scroll-after/gtk.log)
- The captures and logs are local checkout artifacts. The exact functional-gate receipt is available alongside the follow-up evidence. [Functional gate](../../.desktop-attempt/functional-host/exact-revision-native/) · [Follow-up evidence](../../.desktop-attempt/design-review/)
